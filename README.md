# JavaCore — SkyShop

Java Core study project built around a small shop/search domain.

## Structure

The source tree contains products, basket logic, articles, a search engine, comparators, utility code, and custom exceptions under:

```text
src/org/skypro/skyshop/
```

The runnable entry point is `App.java`.

## Run

This repository is a plain Java source project rather than a Maven/Gradle build. Open it with a JDK configured in your IDE, or compile the sources directly with `javac`.

IDE-specific files (`.idea/`, `*.iml`) are intentionally kept out of version control.
